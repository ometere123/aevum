# Demonstration path

Connect a wallet on Studionet, create a draft, register two to four public HTTPS sources, and seal the charter. Fund the Vault, inspect the current steward and epoch allowance, nominate a successor, and trigger a due review. Follow the transaction lifecycle until the review is finalized, then re-read Core and show that the Vault follows its spending flag and steward. Use short intervals only in a controlled demo configuration; production-like charters should use longer review windows.

The meaningful proof is the state consequence: an ACTIVE result preserves spending and stewardship, a DORMANT result without an eligible successor disables spending, and an eligible successor can rotate the steward only after a validated dormant review.
