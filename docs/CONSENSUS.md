# Continuity consensus

The leader returns only bounded activity and successor enums, source support, excerpts, and a compact reason. The validator rejects malformed structure, unsupported outcomes, absent grounded evidence for ACTIVE, invalid excerpts, and successor eligibility without dormancy. Unavailable or malformed evidence remains `INSUFFICIENT_EVIDENCE`; it never forces stewardship rotation.

Deterministic post-consensus code changes status, spending availability, and steward identity. Models never calculate transfer amounts. The sealed definition hash covers mission, timing, treasury rules, and ordered sources.
